# Divex Labs — 30s Instagram Reel Production Package
**Working title:** "Your Agency Owns Your Code"
**Format:** 1080×1920, 9:16, 30fps master (60fps for UI screen captures), 30.0s
**Audio language:** Hinglish (Romanized), Indian-accent VO — confident, professional, zero fluff
**Objective:** Scroll-stop in ≤1.5s → DM trigger keyword `BUILD` → qualified B2B leads

---

<strategy_scratchpad>

**Strongest pain point**
A founder's real fear isn't "slow developers." It's *paying for months and still not owning anything.*
- 6-month timelines, monthly retainers, and at the end the agency controls the repo, the hosting, and the API keys.
- Or the no-code stack "works" until 500 users — then it breaks, and migrating off it means rebuilding from zero.
- Translation into founder math: **burned runway + delayed revenue + a hostage asset.**

So the hook attacks *ownership* (emotional, high-status), the body proves *speed* (visual flex), and the close sells *sovereignty* (100% yours). Speed alone is a commodity claim; ownership + speed is a positioning claim.

**Terminal → Bento transition (the "satisfaction moment")**
1. Pure #07090E black. One blinking cyan cursor. Mechanical keystrokes type `divos build --spec ./client-crm.md`.
2. On ENTER: a single sub-bass hit. Log lines stream fast (agents spawning: `architect`, `backend`, `frontend`, `qa`).
3. The log lines don't cut away — they *collapse upward* into thin 1px cyan lines that become the borders of glass tiles.
4. Tiles snap into a 3×3 Bento grid one by one (glass clicks, ~80ms apart), each tile filling with a live UI state.
5. Camera does a slow 105%→100% push-out to reveal the whole dashboard. Chaos (text) → order (product). That reveal is the dopamine hit.

</strategy_scratchpad>

## 3. Editor's Visual & Motion Prompts

### Color system
| Token | Hex | Use |
|---|---|---|
| Obsidian base | `#07090E` | Every background. Never pure #000. |
| Glass surface | `rgba(255,255,255,0.04)` + 24px backdrop blur | Bento tiles, cards, CTA pill |
| Hairline border | `rgba(255,255,255,0.08)` 1px | Default tile border |
| Telemetry cyan | `#22D3EE` | Cursor, active borders, keywords, "BUILD" |
| Emerald success | `#10B981` | Checkmarks, counters, "Yours" |
| Kinetic white | `#F5F7FA` | Headlines |
| Muted text | `#8B93A7` | Labels, handles, secondary lines |
| Alert red | `#EF4444` | Old-way only ("OWNS", error nodes, strike-throughs) |

**Grade:** The "old way" segment (0:03–0:08) is desaturated −60%, slight green-grey cast, +grain. Everything from 0:08 onward is clean, high-contrast, deep blacks, cyan/emerald as the only saturated colors. The color shift itself tells the story.

**Glow recipe (borders):** 1px cyan line + outer glow `0 0 12px rgba(34,211,238,0.35)` + a second wide glow `0 0 40px rgba(34,211,238,0.12)`. Animate glow intensity 0.6→1.0 on tile activation.

### Typography
- **Headlines:** Geist Sans or Inter Display, Bold/Semibold, tracking −2%, ALL CAPS for kinetic headlines. 88–110pt on the 1080 canvas.
- **Code / terminal / labels:** JetBrains Mono or Geist Mono, Regular, 28–34pt.
- **Rule:** Max 6 words on screen at any moment. One headline per beat. Never two animated text layers fighting.
- **Burned-in captions:** Yes — ~60% of Reels are watched muted. Hinglish captions in Inter Semibold 44pt, white with 60% black pill background, placed at y≈1250px. Highlight the punch word of each line in cyan.

### Motion rules
- Easing: `cubic-bezier(0.16, 1, 0.3, 1)` (expo-out) for all pop-ins; 250–350ms.
- Bento tile stagger: 80ms. Scale from 96%→100% + opacity 0→1 + border glow on.
- Camera: slow digital pushes only (105%↔100%). No handheld shake except the single padlock impact.
- Cut on beat: set music to 100–110 BPM; every pattern interrupt lands on a downbeat.
- Pattern interrupt every 2.5–3s (8 marked above). If an edit holds longer than 3s without a new element, add a counter tick, border pulse or zoom.

### Screen-recording overlays
- **Use real recordings where possible:** record actual DivOS terminal runs, a real (or staging) SaaS dashboard, and RADAR's real UI at 60fps, 2× resolution, then crop/zoom in post. Real UI reads as credibility; stock "hacker" footage reads as cheap.
- Strip OS chrome (menu bars, docks, browser tabs). Re-frame each capture inside a glass tile with 24px radius.
- **Blur or replace any real client data, emails, API keys, or lead names** with dummy data before export.
- Add a subtle scanline/noise overlay at 3% opacity across the whole timeline to unify captures with motion graphics.

### Instagram safe zones (1080×1920)
- Keep all text out of: top 220px, bottom 420px (caption + buttons), right 140px (like/comment/share rail).
- Primary headline zone: y = 300–900px. Captions: y ≈ 1250px.

### Integrity check before publishing
- Every number shown on screen (lead counts, latency, test counts, "Month 6" invoices) must be either from a real demo run or clearly a UI illustration — **don't display client counts, revenue figures, or delivery-time guarantees you can't back up.** B2B buyers screenshot claims and ask about them on the sales call.

### Export
- H.264, 1080×1920, 30fps, 15–20 Mbps, AAC 320kbps, −14 LUFS. Cover frame: the 100% sovereignty card (pick at 0:22.5 and upload as custom cover).
